# BridgeLabz-SIPP-Training-2026
Welcome to my **BridgeLabz SIPP 2026** repository.

## About the Program

This repository contains the code, assignments, and practice problems completed during the **BridgeLabz Summer Internship Preparation Program (SIPP) 2026**.

The program is focused on building strong problem-solving skills and preparing for technical interviews through consistent coding practice and hands-on learning.

## What We Are Learning

During this program, we are studying:

* Data Structures and Algorithms (DSA)
* Java Programming
* Object-Oriented Programming (OOP)
* Generics and Collections Framework
* SQL and Database Management
* Problem Solving Techniques
* Coding Interview Preparation
* LeetCode Practice

## 160 Hours Coding Journey

As part of the **BridgeLabz SIPP 2026** program, we are completing **160 hours of coding practice**. This intensive learning journey is designed to strengthen our programming fundamentals, improve logical thinking, enhance problem-solving abilities, and develop coding proficiency through consistent practice.
